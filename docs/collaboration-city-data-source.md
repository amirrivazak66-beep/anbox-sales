# دادهٔ شهرهای ایران

فهرست انتخاب شهر در `scripts/collaboration-requests.js` از مجموعهٔ [sajaddp/list-of-cities-in-Iran](https://github.com/sajaddp/list-of-cities-in-Iran) نسخهٔ 3.1.2، خروجی `dist/json/cities-filtered.json` و `dist/json/provinces.json` تهیه شده است. دادهٔ مبنا بر تقسیمات کشوری تا پایان ۱۴۰۴ استوار است.

- ۳۱ استان و ۱۴۸۱ رکورد شهر واقعی؛ نام‌های تکراری در یک استان برای منوی کشویی یکسان ادغام می‌شوند (۱۴۷۹ گزینهٔ یکتا).
- ۱۹۱ ناحیهٔ شهری مشتق‌شده در مجموعهٔ `urban-zones` عمداً به‌عنوان شهر مستقل نمایش داده نمی‌شوند.
- مجوز منبع: GNU GPL v3.0؛ استفاده و توزیع دادهٔ اقتباس‌شده باید با شرایط این مجوز سازگار باشد. پیش از انتشار، مجوز پروژهٔ مقصد باید بررسی شود.
- شهرهای قدیمی خارج از فهرست در فرم ویرایش فقط برای حفظ دادهٔ موجود نشان داده می‌شوند؛ امکان واردکردن دستی شهر جدید وجود ندارد.
- تاریخ‌های قدیمی و متن‌های غیرتاریخی بدون تغییر باقی می‌مانند، مگر کاربر تاریخ جدیدی انتخاب کند.
